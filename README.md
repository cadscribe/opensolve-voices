# OpenSolve lesson voices

Prebuilt voice bundles for the lessons in [OpenSolve](https://github.com/cadscribe): one bundle per course and language, AAC-LC 48 kbit/s, in the release `voices`. The app downloads a bundle once, checks its SHA-256 and keeps it.

The speech is AI-generated: German by ElevenLabs, English by Kokoro-82M. No person speaks it.
